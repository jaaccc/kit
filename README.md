# kit

kit is a minimalist and lightweight browser extension with tools for web and graphic designers.

pick colors and fonts from the page you're looking at and come back to them later. kit stores what you collect in the recent section so you won't lose them.

features

- pick colors or fonts from a webpage
- view recently collected colors and fonts
- delete items you no longer need

no accounts or unnecessary features, just a simple way to grab colors and fonts from the web.

technologies: css, html, javascript, markdown
